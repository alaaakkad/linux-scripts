# Linux Automation & Monitoring Scripts

Welcome to my personal toolbox of Bash scripts. This repository is dedicated to automating system administration tasks, monitoring server performance, and optimizing Linux environments.

## Available Scripts

* **[Server Performance Stats](./server-stats/)** - A lightweight script to analyze CPU, Memory, Disk usage, and top running processes.

## How to Use This Repository

To use any script from this repository, clone it to your local machine:

```bash
git clone https://github.com/alaaakkad/linux-scripts.git
cd linux-scripts
```
